Sobre mí

Soy Marvin Benítez, desarrollador web con una fuerte pasión por crear soluciones digitales funcionales y bien estructuradas. Me considero alguien en constante aprendizaje, con metas claras y ganas de crecer en la industria.

Mi experiencia abarca tanto el frontend — con HTML, CSS y JavaScript — como el backend, trabajando con Python, Django, Wagtail y Node.js. También tengo sólidos conocimientos en gestión de bases de datos en entornos de prueba: MySQL, Oracle y SQL Server.

Adicionalmente, manejo el ecosistema de Microsoft Power Platform: Power Apps, Power Automate y Power BI, lo que me permite construir soluciones empresariales de automatización y análisis de datos.

Me desenvuelvo cómodamente en entornos Windows, macOS y Linux, y tengo experiencia con la línea de comandos de Linux para gestión de servidores y entornos de desarrollo.

Mi objetivo es seguir desarrollando proyectos reales que resuelvan problemas concretos, colaborar con equipos multidisciplinarios y consolidarme como desarrollador web profesional.

Buscando oportunidades para aplicar y expandir mis habilidades.
